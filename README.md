# Proxy Manager

## Развернуть с нуля
```
bash install.sh
```
или с доменом: `DOMAIN=example.com bash install.sh`

## Обновить работающую систему
Админка → 🐙 GitHub → «Обновить файлы».

`install.sh` самодостаточный: внутри все модули, шаблоны и расширение.
Каталог `files/` — те же файлы россыпью, для точечного обновления.
